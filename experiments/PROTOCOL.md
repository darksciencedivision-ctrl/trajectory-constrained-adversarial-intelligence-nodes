# TCAIN Initial Evaluation Protocol

Compare C0 single pass, C1 self-refine/self-consistency, C2 conventional debate, C3 mixture aggregation, C4 full TCAIN node, and C5 ablations under matched model-weighted compute. Use deterministic code and math tasks first, then blinded system-design and evidence-synthesis review. Freeze prompts, contracts, schemas, and analysis plan before first scored run. Publish excluded runs and reasons.
