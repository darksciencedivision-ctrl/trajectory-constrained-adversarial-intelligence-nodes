# Trajectory-Constrained Adversarial Intelligence Nodes (TCAIN)

A working thesis and experimental research program for trajectory-first multi-model reasoning under structured perturbation, constitutional constraint, governed mutation, and recursive orchestration.

## Status

**Working thesis v1.0. Not peer reviewed. Evaluation pending.** The complete eight-model node has not yet been benchmarked. This repository presents a falsifiable architecture and test program, not a validated performance claim, AGI claim, or consciousness claim.

## Central thesis

For complex multi-model reasoning, final work may be improved more reliably by controlling and measuring the trajectory of an evolving shared state under adversarial and constitutional pressure than by optimizing only for consensus, majority vote, or fixed debate rounds.

## Core design

- Four directional perspective cells, two heterogeneous models per cell in the base node.
- A versioned shared work state rather than transcript-centric coordination.
- Controlled adversarial engines that inject plausible wrongness to test recovery.
- Constitutional engines that preserve objective, evidence, constraints, and authority.
- A conductor with explicit merge policy, measured dominance, and no self-approval.
- External validator veto and human-controlled canonical promotion.
- Trajectory metrics for drift, issue load, recovery, correction gain, diversity, cost, and stability.
- Recursive composition only after single-node benefit is demonstrated.
